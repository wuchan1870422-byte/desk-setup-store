# 正式接单之前必须完成

目前是公开可测试的英文演示店，不能付款、不能下单。A$29 / A$79 / A$39 的商品售价、A$9 运费、商品参数、供应商和物流时间均为演示资料。不要把当前网站当成已运营的商店推广销售。

1. **确认实际商品和供货。** 选择真实供应商、买样检查、核实材料尺寸与包装、取得真实图片使用权，明确可供数量、采购价和缺货处理。货架承重等未经检测的信息不能宣传为已验证。
2. **核算可实现的售价。** 把采购、跨境运输、包装、支付费、可能的税费和退换损耗算清楚，确认 AUD 最终价格、GST 和进口责任的适用安排，并向客户清晰展示。
3. **测试澳大利亚配送。** 确认发货地、承运商、追踪、处理时长、运输时长、偏远地区和邮政信箱限制，实际跑通样品配送，并落实丢件、损坏、延误处理。
4. **补齐经营信息和政策。** 确认实际卖家身份、适用经营要求、工作邮箱、联系安排、可执行退货地址及处理流程。根据实际业务定稿配送、退换货和隐私政策；澳大利亚消费者的法定保障不能被店铺政策排除。海外商家面向澳大利亚消费者销售同样需考虑 Australian Consumer Law。
5. **接入官方 PayPal，并先在 Sandbox 验证。** 确认商家账户是否支持实际经营主体、国家和币种；开发独立服务端创建/捕获订单，服务端重新核价，验证支付结果，处理幂等、取消、支付失败、退款与争议。保密凭据仅存于服务端。当前静态购物车不能作为支付凭据或订单系统。
6. **建立最小订单交付流程。** 支付成功后产生可追踪订单、通知客户、安排供货发货、上传追踪并提供售后。只收集必要个人信息，确认访问权限、保存期限、第三方处理和跨境传输说明。
7. **完成上线验收。** 真实手机和桌面浏览器测试商品、加购、数量、删除、刷新、直接链接、导航和错误页；检查完整支付与退款流程。连接自己的域名后更新站点 origin，并重新构建。
8. **最后再解除演示模式。** 替换所有演示商品和示例邮箱，定稿政策，移除合适的演示标识。只有以上事项完成后才重新开发并审核付款开关、允许搜索引擎索引、向消费者接受订单。
